## Featured Project

### PulseGate — API Gateway & API Management Platform

A production-minded platform for secure API routing, traffic management,
analytics, observability, and developer-facing API workflows.

**Highlights:**

- API-key and JWT authentication
- Rate limiting, caching, timeout, and retry policies
- Dynamic, host-based, and weighted routing
- PostgreSQL and Redis integration
- Admin Dashboard and Developer Portal
- Prometheus, Grafana, OpenTelemetry, and Loki
- Docker Compose and Kubernetes deployment
- Automated tests and release validation
